# Provenance and transformation

Original pack text was newly synthesized for Pachecodes / Jesus Pacheco / Akitá Labs. Installed sources were read-only inputs, not a redistributable bundle. No incident logs, source support scripts, provider adapters, templates, or media were copied. The task template and repository tooling were newly authored for this pack.

## Evidence threshold and limits

The selected procedure sources carry explicit local author metadata identifying the owner's local authoring agent, including one joint agent attribution. The artifact-first source additionally has a local creation-tool receipt following an explicit owner request to make that method a skill. These support local development provenance, not an exhaustive third-party intellectual-property audit. Public attribution names the human/organization steward; agent-assisted authorship is not hidden. The owner must independently confirm rights before publication. General ideas such as maker/checker separation, hashing, bounded budgets, and readback are not claimed as exclusive inventions.

Sources without this threshold were omitted rather than relabeled. Author metadata alone is not cryptographic evidence; no installed Git history was available. No confidential creation transcripts or local paths are shipped here.

## Exclusions

Known imported/runtime reference families (including the Hermes runtime skill, Codex/Claude CLI skills, HyperFrames and its animation adapters, external design skills) are not licensed here. Release-verification, release-target-safety, multi-repo-targeting, evidence-based-claims, documentation-accessibility, generic realtime-pipeline and authority-guarded-effect sources lacked sufficient verified authorship for inclusion in this pass. Their installed presence, customized examples, or generic agent author fields were not treated as original-owner proof. Private/proprietary and client-specific material is excluded regardless of author label. No attribution or license here applies to excluded sources, external runtimes, libraries, or diagram engines.
