# Eight-skill overview

[Back to README](../../README.md#the-eight-skills)

Original editorial diagram: eight independent procedures, not a logo, product interface,
or mandatory execution sequence. No private inputs, external fonts, scripts, or fetched assets.

## Text equivalent

- **pache-artifact-first**: Make the useful artifact.
- **pache-bounded-feature-loop**: Bound one implementation.
- **pache-frozen-evidence-review**: Review the exact bytes.
- **pache-safe-recurring-automation**: Plan repeating work safely.
- **pache-completion-verification**: Verify what actually happened.
- **pache-bounded-decision-routing**: Compare finite choices.
- **pache-agent-integration-preflight**: Check integration boundaries.
- **pache-private-diagram-workflow**: Render without leaking source.

## Local preview

From the repository root, extract the SVG to an explicitly chosen scratch directory
and render with an installed `rsvg-convert`. This optional preview does not install skills.

```sh
python3 -c 'from pathlib import Path; s=Path("docs/assets/skill-overview.md").read_text(); print(s.split("```svg\n",1)[1].split("```",1)[0],end="")' > <scratch-directory>/skill-overview.svg
rsvg-convert <scratch-directory>/skill-overview.svg -o <scratch-directory>/skill-overview.png
```

Replace the scratch placeholder first. SVG is potentially active content: inspect source
before rendering other diagrams. This source uses only local shapes and text.
